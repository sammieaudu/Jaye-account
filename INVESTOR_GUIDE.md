# Investor local test guide

Choose Investor preview in Test as. The workspace shows that no approved snapshot exists. This is intentional: an investor must never see the live financial dashboard or supporting personal records. Direct live-data API calls are rejected.

Future access will be read-only to approved, frozen USD snapshots with period, rates, definitions and version history. Constant currency, aggregate category/month detail and logged watermarked downloads will be available only after their Phase 2 approval gates. No financial performance is inferred or invented for this preview.
